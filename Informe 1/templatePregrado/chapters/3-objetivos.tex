\chapter{Objetivos}
\label{cap:objetivos}

\section{Objetivo general}
Desarrollar una metodología sistemática para la extracción y análisis de competencias a partir de datos no estructurados, con el fin de facilitar la comparación entre programas académicos de Ingeniería Informática en Chile


\section{Objetivos específicos}
\begin{enumerate}
    \item Diseñar una metodología sistemática para la recopilación, procesamiento y análisis de datos no estructurados provenientes de programas académicos de Ingeniería Informática.
    \item Implementar la metodología propuesta mediante una herramienta computacional que permita automatizar el flujo de procesamiento y análisis de los datos.
    \item Validar la metodología propuesta utilizando información real de programas de Ingeniería Informática en Chile.
\end{enumerate}
